group tools - protótipo do painel redesenhado

Protótipo fiel ao produto na versão 0.1.1, para validação, não aprovado. Nada é salvo de verdade: os dados são de exemplo e voltam ao original ao recarregar. Use os controles à esquerda para mudar tema, largura e estado; use o painel simulado à direita como na barra lateral do VS Code.

Atalhos (organização sempre ativa)
  • Espaço ou Enter na alça: pega; setas movem; ←→ trocam de grupo; Espaço solta; Esc devolve. Não há reordenação em lista filtrada (busca, favoritos, só quebrados).
  • Alt+↑/↓ no item ou no grupo: move um passo sem pegar.
  • Ctrl+Z: desfaz a última alteração.
  • Barra de status: Tab até um item fixado abre o card (como o tooltip nativo no foco); Esc fecha; Enter abre o grupo.
  • Alt+Shift+C: recolhe ou expande todos os grupos.
  • Duplo clique no nome do grupo: renomear.

Vista nativa simulada. Clique no ícone group tools (ou num ícone fixado) para voltar ao painel.

Alça de mover: Espaço ou Enter pega o item ou o grupo; setas movem; setas para os lados trocam de grupo; Espaço solta; Esc cancela. Alt mais seta para cima ou para baixo move um passo em qualquer item ou grupo.
